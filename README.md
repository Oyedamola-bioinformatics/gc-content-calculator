# gc-content-calculator
GC Content Calculator and DNA to Protein Translator - Calculates GC%, Reverse Complement, and Translates DNA to Protein for Bioinformatics Analysis
- GC Content % - How much G and C in the DNA
- Reverse Complement - The opposite strand of DNA
- Protein Translation - Translates DNA codons to amino acids

## Example
DNA: ATGCGACTATAGCTACTATACGATACGATACGATATATATACGATACGA
Length: 49
GC Content: 34.69%
Reverse Complement: TCGTATCGTATATATATCGTATCGTATCGTATAGTAGCTATAGTCGCAT
Protein: MRL*LLYDTIRYIYDT

## Why is this important?
- Low GC Content (34.69%) means AT-rich region - this is the Origin of Replication where DNA opens easily
- This is used in real labs for PCR primer design, genome analysis, and disease detection
- Built with Python for Bioinformatics AI Specialist portfolio
